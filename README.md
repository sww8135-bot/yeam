# 📚 ช่วยในการเรียน — Student Study Planner

เว็บแอปช่วยจัดการชีวิตนักเรียน/นักศึกษาในที่เดียว: **ตารางเรียน · การบ้าน · กำหนดการสอบและแผนอ่านหนังสือ**
ทำงานบนเบราว์เซอร์ล้วน ๆ (ไม่ต้องมีเซิร์ฟเวอร์/ฐานข้อมูล) และ **บันทึกข้อมูลลง LocalStorage** จึงไม่หายเมื่อรีเฟรชหน้า

## ✨ ฟีเจอร์

| หน้า | สิ่งที่ทำได้ |
|---|---|
| 🗓️ **ตารางเรียน** | ตารางรายวันแบบจันทร์–อาทิตย์ พร้อมไอคอนและสีประจำวิชา · เพิ่ม/แก้ไข/ลบวิชา (ชื่อวิชา รหัสวิชา วัน-เวลา ห้อง ผู้สอน) · เรียนได้หลายวันในวิชาเดียว · ไฮไลต์วันนี้และคาบที่กำลังเรียน · เตือนเมื่อเวลาเรียนทับกัน |
| 📝 **การบ้าน** | แยกงานตามวิชา · ป้ายความสำคัญ High / Medium / Low · ติ๊กเมื่อทำเสร็จ · กรองตามสถานะ/ความสำคัญ/วิชา · แถบความคืบหน้า · บอกจำนวนวันที่เหลือหรือเลยกำหนด |
| 🎓 **สอบ & อ่านหนังสือ** | นับถอยหลังวันสอบ (เปลี่ยนสีเมื่อใกล้ถึง) · ขอบเขตเนื้อหา วัน-เวลา-สถานที่ · เช็กลิสต์แผนอ่านหนังสือพร้อมแถบความคืบหน้า |
| 🎨 **อื่น ๆ** | โหมดมืด/สว่าง (จำค่าไว้ และตามระบบเครื่องเป็นค่าเริ่มต้น) · แบนเนอร์พร้อมรูปโปรไฟล์และโลโก้ที่อัปโหลดเองได้ · สำรอง/นำเข้าข้อมูลเป็นไฟล์ JSON · Responsive (เมนูล่างบนมือถือ เมนูบนบนคอมพิวเตอร์) |

## 🗂️ โครงสร้างโปรเจกต์

```
study-planner/
├── index.html                 # หน้าเว็บหลัก (โหลด Tailwind, Lucide, ฟอนต์ผ่าน CDN)
├── manifest.webmanifest       # ข้อมูลแอป + App Icon (ติดตั้งลงหน้าจอมือถือได้)
├── README.md
├── assets/
│   ├── images/
│   │   └── logo.svg           # โลโก้เริ่มต้น (ใส่ app-preview.png / ภาพประกอบเพิ่มที่นี่)
│   └── icons/
│       ├── favicon.svg        # Favicon (เวกเตอร์)
│       ├── favicon-32.png     # Favicon สำรองสำหรับเบราว์เซอร์เก่า
│       ├── apple-touch-icon.png   # 180×180 สำหรับ iOS
│       ├── icon-192.png       # App Icon สำหรับ Android/PWA
│       └── icon-512.png
├── css/
│   └── style.css              # สี/คอมโพเนนต์/โหมดมืด (ใช้ CSS Variables)
└── js/
    ├── utils.js               # ค่าคงที่ วันที่ escape HTML ย่อรูป
    ├── store.js               # LocalStorage + ตรวจสอบ/ทำความสะอาดข้อมูล + ข้อมูลตัวอย่าง
    └── app.js                 # การแสดงผล 3 หน้า ฟอร์ม และการทำงานทั้งหมด
```

## ▶️ วิธีใช้งานบนเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลด Tailwind CSS, Lucide Icons และฟอนต์จาก CDN)

หรือรันเซิร์ฟเวอร์ชั่วคราวเพื่อทดสอบ:

```bash
npx serve .          # หรือ python3 -m http.server 8000
```

> กดปุ่ม **“ใส่ข้อมูลตัวอย่าง”** ในหน้าแรก เพื่อดูหน้าตาแอปพร้อมข้อมูลสมมติ

## 🚀 นำขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน GitHub (เช่น `study-planner`) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ โดยให้ `index.html` อยู่ที่ราก (root) ของ repo
   ```bash
   git init
   git add .
   git commit -m "first commit"
   git branch -M main
   git remote add origin https://github.com/<ชื่อผู้ใช้>/study-planner.git
   git push -u origin main
   ```
2. ไปที่ **Settings → Pages**
3. หัวข้อ **Build and deployment** เลือก **Source: Deploy from a branch**
4. เลือก Branch **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
5. รอประมาณ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/study-planner/`

## ▲ นำขึ้น Vercel

**วิธีที่ 1 — ผ่านเว็บ (ง่ายที่สุด)**
1. อัปโหลดโปรเจกต์ขึ้น GitHub ตามขั้นตอนด้านบน
2. เข้า [vercel.com](https://vercel.com) → **Add New… → Project** → เลือก repo นี้
3. **Framework Preset: Other** ไม่ต้องใส่ Build Command และไม่ต้องใส่ Output Directory
4. กด **Deploy**

**วิธีที่ 2 — ผ่านคำสั่ง**
```bash
npm i -g vercel
vercel --prod
```

## 🖼️ ปรับแต่งรูปภาพและไอคอน

- **โลโก้/รูปโปรไฟล์:** กดที่รูปวงกลมบนแบนเนอร์ → เลือกรูป (เก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน)
- **เปลี่ยนโลโก้เริ่มต้นของโปรเจกต์:** แทนที่ไฟล์ `assets/images/logo.svg`
- **เปลี่ยน Favicon / App Icon:** แทนที่ไฟล์ใน `assets/icons/` โดยใช้ชื่อและขนาดเดิม (`favicon-32.png` 32×32, `apple-touch-icon.png` 180×180, `icon-192.png`, `icon-512.png`)
- **เปลี่ยนสีธีม:** แก้ตัวแปร `--primary` และกลุ่มตัวแปรใน `css/style.css` (ส่วน `:root` และ `.dark`)

## 💾 เรื่องข้อมูล

- ข้อมูลอยู่ใน LocalStorage ภายใต้คีย์ `studyPlanner.v1` ของเบราว์เซอร์/เครื่องนั้น ๆ — **ไม่ส่งไปที่ใด**
- ข้อมูลจะหายหากล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ หรือเปลี่ยนเครื่อง/เบราว์เซอร์ → ใช้ปุ่ม **ฐานข้อมูล (ไอคอนบนขวา)** เพื่อดาวน์โหลดไฟล์สำรอง `.json` และนำเข้าภายหลังได้
- ข้อมูลที่นำเข้าจะถูกตรวจสอบและทำความสะอาดก่อนใช้งานเสมอ

## 🛠️ เทคโนโลยี

HTML5 · [Tailwind CSS](https://tailwindcss.com) (CDN) · JavaScript (Vanilla, ไม่ต้อง build) · [Lucide Icons](https://lucide.dev) · ฟอนต์ Noto Sans Thai และ Prompt

> ต้องการต่อยอดเป็น React/Next.js? โครงแยก `store.js` (ข้อมูล) กับ `app.js` (การแสดงผล) ช่วยให้ย้ายตรรกะไปเป็น hook/คอมโพเนนต์ได้ง่าย
